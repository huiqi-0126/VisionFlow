# 快剪输入与交付规范

## 用户需要提供

- 一条参考视频：用于分析剪辑节奏、镜头循环、转场、调色和音效落点。
- 两条或以上原始素材：可以逐个提供路径，也可以提供一个文件夹。
- Caption Title：画面中央或指定位置显示的标题文字。
- 可选强调词：例如标题为 `FOCUS ON DESIGN`，白色主词为 `FOCUS`，黄色强调词为 `ON DESIGN`。
- 可选输出要求：9:16 或 16:9、分辨率、是否保留参考音效、标题位置和颜色。

## 推荐的用户指令

```text
使用 $quick-cut。
参考视频：/path/reference.mp4
素材：/path/1.mp4 到 /path/6.mp4
Caption Title：FOCUS ON DESIGN
黄色强调词：ON DESIGN
输出：9:16，保留参考视频节奏和音效。
```

如果用户没有提供 Caption Title，Codex 必须先询问：

```text
请提供画面中显示的 Caption Title 文字；如需双色，请同时说明白色主词和黄色强调词。
```

用户明确回复“不要标题”后，才可以无标题继续。

## 默认交付

- 最终 MP4：H.264、AAC 48 kHz、BT.709。
- 时间线清单或 JSON：记录参考片切点和素材映射。
- 预览联系表：用于快速检查构图、标题和调色。
- 原始素材保持不变。
